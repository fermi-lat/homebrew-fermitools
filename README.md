# Fermi-lat Fermitools

## How do I install these formulae?

`brew install fermi-lat/fermitools/<formula>`

Or `brew tap fermi-lat/fermitools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "fermi-lat/fermitools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
